# Теория баз данных. Программирование MS SQL Server

Учебный репозиторий по дисциплине «Теория баз данных. Программирование MS SQL Server».

## Стек технологий
* **СУБД:** Microsoft SQL Server
* **Язык:** T-SQL
* **Инструменты:** SSMS (SQL Server Management Studio) / Azure Data Studio

## Структура репозитория

| Папка | Содержимое |
| :--- | :--- |
| `homework/` | Домашние работы |
| `practice/` | Практические работы, выполненные на занятиях |
| `theory/` | Теоретические материалы и конспекты |

## Домашние работы

Каждая домашняя работа находится в отдельной папке и имеет свой `README.md` с описанием задания. 

**Пример структуры папки с работой:**

```text
homework/
└── DB_2026-09-20_1/
    ├── README.md        # Описание задания и выводы
    ├── screenshots/     # Скриншоты выполнения запросов
    ├── sql/             # SQL-скрипты с решениями
    └── _source/         # Исходные данные (дампы БД, csv и т.д.)
